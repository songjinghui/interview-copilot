## 如何发现并复现

美团公开首页 HTML 指向 `entry-main-9361c032.js`，该入口脚本给出业务脚本地址；业务脚本明确使用 `getJobList` 与 `getJobDetail` 两个查询接口，列表组件提供分页与筛选参数结构。没有猜测私有接口，也没有使用登录凭据。

两条查询均使用 POST；POST 在这里表示官网的读取方式，**没有调用申请、简历保存或消息接口**。单轮固定第一页、一个岗位，随后核对对应详情，不自动翻页或重试。

```powershell
python -X utf8 validation/probe.py --companies 美团 --skip-platforms --meituan-job-sample --output-dir validation/results/public-job-2026-11-03
```

遇到 HTTP 错误、非 JSON、业务失败、空列表、缺少职责或要求、详情编号不一致时，分别记录失败或缺失状态，不标为成功。

## 本轮阻点与当时的后续任务

1. **动态页面**：本轮浏览器工具返回空连接列表，无法核对页面实际渲染、申请按钮与表单。阿里首页脚本中的社会招聘路径访问后重定向回集团首页，尚未定位具体业务板块的可用列表。腾讯两个首页脚本资源直接读取返回 403，未继续规避限制。上述现象都不能证明这些公司不支持接入。
2. **目标筛选**：用户的具体岗位方向、城市和招聘类型尚未落实到验证配置；后续用实际条件检验筛选正确性、岗位更新和失效处理。
3. **代投**：需要能操作的浏览器、对应招聘账号、用户选定岗位和授权材料。先检查表单与回执，再验证一次明确授权的提交；现阶段没有可供确认的真实投递内容。
4. **反馈**：需要确定用户实际接收招聘反馈的渠道，再验证读取、岗位关联、重复通知及改期处理。当前没有读取私人消息。
