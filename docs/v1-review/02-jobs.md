# M2：目标与真实岗位发现

状态：草案 v1，待顺序审阅。返回[总览](README.md)；共用[data-flows](data-flows.md)。

## 1. 结果与边界

用户说明岗位关键词和城市（可不限），可补充薪资等硬条件/偏好；系统取得真实岗位与JD、给出有依据的匹配和冷却期提示。用户可以选择值得继续的岗位。

至少一个已验证来源的产品搜索是本块完成条件；手工粘贴JD、单个链接读取、外部Agent曾经找到样本均不能替代。第二个真实来源用于验按能力扩展；不要求首版覆盖所有候选平台。猎聘、BOSS、企业官网按原愿景保留为候选，具体接入顺序由实测决定。

## 2. 功能拆分

| 子段 | 操作与结果 |
|---|---|
| M2a 目标与岗位输入 | 少量必要条件、保存/修改目标；导入链接或正文并保存来源与完整性；已有目标优先展示 |
| M2b 搜索与比较 | 一个来源的列表/详情接入；按需搜索、逐源状态、条件匹配、原文依据、缺失信息和冷却期 |
| M2c 扩展验证 | 增加第二个真实来源的适用能力；原核心流程复用、历史保留、局部失败不阻断 |

用户在M1有简历就复用；目标偏好仍须确认，不能从过往工作地点推断希望去的城市。使用资料做匹配时显示所用版本。搜索中能看已返回结果；再次进入优先看最近结果和当前条件，新增搜索不会覆盖旧条件快照。

## 3. 数据拆分与流程

| 对象 | 数据与交互 |
|---|---|
| 目标 | profile_targets保存用户条件；SearchJobs创建时固定条件内容及revision |
| 来源 | sources/source_capabilities/source_accounts分别保存安装配置、分项能力证据、稳定账号；只启用已实现能力 |
| 执行与匹配 | background_tasks→fetch_runs→search_matches；结果关联JD版本，解释关联条件及原句 |
| 岗位 | jobs按(source_key,external_key)稳定识别；job_versions保存职责/要求等不可变内容 |
| 观察 | job_observations保存每次获取时间/方式/原始依据；内容不变不造新版本，A→B→A保留三次变化 |
| 候选冷却期 | 先记录在观察证据中，含适用范围、原文、来源/时间、已知期限；M3创建机会后才转为该机会适用判断 |

SearchJobs读取目标与可用来源→异步获取→校验完整性→保存岗位版本/观察→形成可解释匹配→用户选岗交M3。页面筛选是读取，不创建机会或投递记录。HTTP/浏览器获取失败与“没有符合岗位”分开。

M1资料变化不会改写旧搜索；用户决定重新匹配时创建新输入快照。未知硬条件保留待核实，已知不符可查看；不使用无依据的精准百分比。相似标题只提示疑似重复，跨渠道是否同一机会由用户确认。

## 4. 需要先审清的交互

- 候选行显示岗位/公司、地点薪资、完整性、匹配结论、冷却期状态；选中后展示JD正文和证据。
- 冷却期“无”必须有依据，查不到为“待核实”；该规则从列表就生效，不能等投递后才提示。
- 刷新详情保留历史完整JD，明确当前版本是否仍完整、何时获取；不能用旧正文冒充当前抓取成功。
- 来源失效给对应原因和恢复入口，其他结果保留；配置不要求用户输入程序内部字段。

## 5. 验收

| 编号 | 场景 | 标准 |
|---|---|---|
| M2-A1 | 修改目标后查看旧搜索 | 旧条件和资料版本保持，最新目标只影响新搜索 |
| M2-A2 | 从应用取得真实岗位 | 职责/要求、来源/链接/时间可追溯；缺项如实标注；至少一源完整链可重现 |
| M2-A3 | 同源重复获取、A→B→A内容变化 | 不重复岗位身份；观察更新，内容历史正确 |
| M2-A4 | 一源失败、未知薪资/硬条件/冷却期 | 成功结果仍可看；未知不当作不符或无限制 |
| M2-A5 | 未保存为机会的候选已有冷却期证据 | 列表即可显示适用信息；转M3后保留来源并重新核对适用范围 |
| M2-A6 | 第二个真实来源接入、停用、重新启用 | 核心流程不重写；原来源回归；历史仍可读，无重复记录 |

测试位置：tests/test_job_model.py、test_job_store.py、test_source_registry.py、test_http.py，validation/tests及frontend/tests中的找岗旅程。联网实测保留日期与适用条件，自动化测试用固定样本，不把实时网站当稳定单元测试依赖。

准入：负责人复核可持续来源、实际目标匹配范围和需要的授权/运行依赖。某来源失败先按证据换候选；全部无法满足时才能提出范围取舍，不自行把AI找岗改成纯手工录入。
